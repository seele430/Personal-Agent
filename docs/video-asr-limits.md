# 视频转写：已知精度上限（v1.1 长素材，2026-11-09 定案）

> 结论先行：**在这台 6 GB 显存的笔记本上，用 CPU + faster-whisper，中文技术类长音频的
> 逐句转写 95% 达不到。** 这是实测出来的上限，不是"还没做"。

---

## 1. 实测数据（同一套评分：按关键词命中 + 字符相似度）

### 1.1 合成素材（SAPI，60 句 / 238.8 s）

| 配置 | 命中 | 命中率 |
|---|---|---|
| medium（默认） | 52/60 | 86.7% |
| **large-v3** | **56/60** | **93.3%** |
| large-v3 + 术语表 | 48/60 | 80.0% |
| large-v3 + 关 VAD + beam 10 | 56/60 | 93.3% |
| large-v3 + `condition_on_previous_text=False` | 55/60 | 91.7% |

### 1.2 真人录音（43 句稿子）

| # | 时长 | 关键词命中 | 字符相似度 |
|---|---|---|---|
| 1（语速偏快） | 4:11（不足 5 分钟） | **90.7%** | 87.0% |
| 2（放慢） | 5:04 | **83.7%** | 78.6% |
| 3（素材 2 + 降噪/响度归一） | 5:04 | **86.0%** | 82.6% |

**合成与真人的最好成绩都在 90–93%，没有一次到 95%。**

---

## 2. 错误类型：几乎全是同音字

| 原词 | 转写结果 |
|---|---|
| 幂等 | 密等 |
| 阈值 | 预值 |
| 缓存块 | 缓存快 |
| 调度器 | 调度计 |
| 重试 | 重视 |
| 轨迹 | 轨纪 |
| 日志 | 日支 |
| 按天汇总 | 安天汇总 |

- **没有整句丢失、没有截断**（末句、后半段都转到了）；
- 慢读**不一定**更好：真人素材放慢后 90.7% → 83.7%，说明录音条件（麦距/混响）影响更大；
- 降噪（`highpass=f=80, dynaudnorm, afftdn=nf=-25`）只提升 2.3 个百分点。

---

## 3. 为什么达不到

1. **语言模型先验**：Whisper 对"密等/预值"这类低频技术词会向常见词回退，同音替换几乎是必然；
2. **素材条件**：手机录音 + 普通房间，信噪比不如专业录音；
3. **模型规模已到顶**：large-v3 是本机能跑的极限，再大 CPU 时间不可接受（4 分钟音频已需 12 分钟）；
4. **参数空间已扫过**：术语偏置有害、VAD/beam/上下文继承均无收益。

---

## 4. 这条限制的准确边界（别扩大也别缩小）

**成立**：
- 中文、技术词密集、同音词多的长音频（4 分钟以上）；
- CPU（int8）、faster-whisper medium/large-v3；
- 评分口径是"逐句/关键词命中"与字符相似度。

**不适用**：
- 英文音频（未测，别推断）；
- 短句素材（20 句合成素材实测 95%，通过）；
- 专业录音棚素材（未测）；
- GPU 推理（未测，本机按保护规则不做）。

---

## 5. 对外怎么说（避免过度承诺）

| 不要说 | 应该说 |
|---|---|
| "转写准确率 95%" | "短素材 95%；4 分钟以上中文技术音频约 86–93%，受同音词限制" |
| "换真人素材就能过" | "真人素材实测更差（86.0%），瓶颈是同音词不是音色" |
| "再调调参数就行" | "已试 5 种配置 + 1 次降噪预处理，未达线" |
| "视频总结不能用" | "管线完整，摘要与要点可用；**逐字转写**不要当逐字稿引用" |

---

## 6. 如果将来要突破

按性价比排序：

1. **换 16 GB 以上显存的机器**跑 large-v3 的 GPU 推理（速度、精度都会更好，未测）；
2. **专业录音**（有线麦、近场、安静房间）——预计能到 90% 出头，到 95% 仍不保证；
3. **后处理纠错**（用 LLM 按上下文改同音字）——**这是"猜"，不能计入转写准确率**，
   只能作为"可读性增强"功能，且必须标注"经模型改写"。
