## 2. 逐条判定

- src/tts_api.py：TTS 独立子进程（edge-tts / 系统播放），不是 Agent 工具 exec。D11 明确保留，不并入 tier1；
  它的生命周期由 TTS 路由自己管理，与 run/step/exec 无关。
- src/platform/exec_service.py：**唯一**创建工具/命令子进程的地方（subprocess.Popen），
  子进程会被立即分配进独立 Job Object，取消/超时/输出超限统一 TerminateJobObject。
- src/platform/process_tree.py：降级路径使用 taskkill /F /T（只针对本平台创建的根 PID）。
- src/platform/tier1_runner.py：command 模式下用 subprocess.run 执行平台下发的 argv；
  它本身已经在 Job Object 里，所以它的后代同样被覆盖。
- 其余 src/ 文件（agent.py / agent_stream.py / chat_secure_api.py 等）没有任何 subprocess / Popen 命中：
  allow 工具不再由宿主直接执行。

## 3. 结论

- 工具 exec 的唯一入口是 src/platform/exec_service.py；宿主只做策略、参数与身份检查。
- 保留的 subprocess 命中只有 TTS 与平台自身，二者都不属于“助手工具 exec”。
