# 简历段落（D40）

> 约 200 字，不含「我做了 DSec」这类表述。

**Personal Agent —— 本地 AI 工作台的沙箱执行平台**

把一个本地个人 AI 工作台的「工具执行」从宿主进程搬进自建的沙箱平台：独立工作区、
清洗后的环境变量、Windows Job Object 管辖的进程树，取消时父子进程一起结束；执行链路带
W3C traceparent，宿主与沙箱共享 trace-id。平台侧实现幂等创建、TTL 回收与 410 语义、
节点租约与 cordon/drain、沙箱状态机、每租户配额、启动对账、有界执行队列（数量+时间双上限）、
Bearer 认证与审计。全量 754 个用例；本机压测饱和拐点在 8–12 RPS（≤8 RPS 时 p99 < 550ms），
并据此写了 SLO 草案。

## 更短的一版（60 字）

为本地 AI 助手自建沙箱执行平台：Job Object 管进程树、traceparent 跨进程、幂等/租约/配额/对账/有界队列；754 用例，压测拐点 8–12 RPS。
