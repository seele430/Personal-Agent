## 一、一条主线

```
用户消息
→ 意图与风险路由（Router：只给约束）
→ 能力 / 模型 / 执行类型选择（Router）
→ 平台准入：权限 / 预算 / 审批（确定性策略闸门，非概率）
→ 队列与节点调度（Platform）
→ 本地沙箱执行（Platform）
→ 文件或图表成果（artifact）
→ route + exec + artifact + cost 统一轨迹
```

**验收示例**：「分析这个 CSV，统计缺失值并生成一张图。」

预期轨迹：

```
route_decided(data.analysis)
→ approval_checked
→ exec_queued
→ node_selected
→ exec_succeeded
→ artifact(chart.png)
→ model_usage / cost
```

## 二、职责边界（不可越界）

| 能力 | Router | Platform |
|---|---|---|
| 判断用户想做什么 | ✅ | ❌ |
| 判断是否需要澄清 | ✅ | ❌ |
| 选择能力类型（chat / sandbox_exec / file_op） | ✅ | ❌ |
| 选择模型策略（便宜 / 强 / 本地） | ✅ | ❌ |
| 给出执行类型约束（local_sandbox、超时、资源上限） | ✅ | ❌ |
| 给出风险等级与审批要求 | ✅（建议） | ✅（**确定性闸门最终裁定**） |
| 选择具体节点 | ❌ **禁止** | ✅ |
| 检查配额 / 容量 / 队列 | ❌ | ✅ |
| 创建、执行、取消、回收 | ❌ | ✅ |
| 扩缩容、节点失效、资源残留 | ❌ | ✅ |
| 回退策略（允许哪些备选） | ✅（白名单） | 执行时按实时状态选择 |

两条硬规则：

1. **Router 只提交约束，不提交节点。** 具体节点由平台按实时容量决定，否则会拿过期状态做决策。
2. **权限不能被概率降低。** 高风险操作必须再过一次确定性策略闸门；Router 的置信度再高也不能放行。

### 路由的五个 intent（先覆盖真实能力，不硬凑）

| intent | 含义 | 典型动作 |
|---|---|---|
| `general.chat` | 闲聊 / 问答 | 直接回复 |
| `data.analysis` | 数据分析 | 沙箱内跑 Python，产出图表/报告 |
| `code.execute` | 代码执行 | 沙箱 exec |
| `file.operate` | 文件读写 | 沙箱内文件工具 + 审批 |
| `platform.inspect` | 平台自检 | 查指标/节点/队列 |
| `reminder.manage` | 提醒管理 | 写提醒表 |

`clarify` 是**决策动作**，不是业务 intent：低置信度或高风险歧义时返回 `clarify`。

## 四、指标口径（修订）

### 路由

| 指标 | 口径 | 目标 / 说明 |
|---|---|---|
| 总体准确率 | 冻结 test 集 | ≥ 90%，同时报 macro-F1 |
| 各类 P/R/F1 | 按 5 intent 分别报 | 防多数类掩盖少数类 |
| **高危漏审批** | 测试集中危险操作未进审批 | **必须为 0**，不设比例容忍 |
| 澄清后任务成功率 | 触发 clarify 的样本最终完成率 | 比“澄清率”更有意义 |
| 降级原因分布 | 按原因分类 | 降级不是越低越好，看原因与质量 |
| 成本节省 | 混合 vs 全强模型 | ≥ 40%，**附带质量下降上限**；记录价格快照与模型版本 |
| 路由延迟 | 规则 / 分类器 / 首次冷加载 / 稳定运行分开 | 分开报 p50/p99 |

### 平台

| 指标 | 口径 | 目标 |
|---|---|---|
| 调度均衡度 | **异容量节点用利用率**，同容量可用活跃数 | 利用率标准差越小越好 |
| 调度耗时 / create→ready / 排队 / 执行 | **分开统计** | 不混成一个“延迟” |
| HTTP 202 / 429 / 执行终态 | **分开统计** | 202 不等于成功 |
| 弹性对照 | 固定 vs 弹性：队列等待、p99、背压、资源 | 弹性需证明收益 |
| 回收残留 | 进程/目录/DB 行 | 0 |
| 并发口径 | 明确“累计创建”还是“并发活跃” | 报告里写死 |

### 评估集纪律

1. 200 条只是**开发集**，不据此下强统计结论。
2. 划分 train/dev/test，**冻结 test 集并记录哈希**。
3. **去重后再切分**，防近似语句泄漏。
4. 高危样本**单独足量**构造，不靠总样本比例。
5. 评估对象是「规则 + 分类器 + 澄清」的**完整决策**，不是分类器单独准确率。
6. 置信度必须校准；规则置信度与模型置信度**不能直接混用**。

## 五、弹性闭环（新增，B 线不再是纯观测）

```
desired_capacity = f(running, queued, capacity_per_node, headroom)
   → 扩容：desired > current 且持续 N 个周期
   → 缩容：desired < current 且冷却期已过
   → 记录：scale_event（原因、前后值、耗时）
```

约束：

- 最小/最大容量；
- 扩容要**稳定**（连续 N 次采样才动作，防抖）；
- 缩容要**冷却**（冷却期内不缩，防抖动）；
- 节点失效：立即停止接活，存量按策略迁移或排空；
- 所有决策写审计事件，可回放。

对照实验：同一突发负载下，固定容量 vs 弹性容量，比较队列等待、p99、背压次数、资源占用。
