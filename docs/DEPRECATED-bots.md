# Bot 管理已从前端撤下（2026-11-11）

## 现状

- 侧栏「Bot 管理」入口、`BotsView` 组件、「我的 BOT」侧栏区块已删除；
- `src/bot_api.py` 路由、`bots.db` 与已有 Bot 数据**保留**，未做迁移或删除；
- 聊天默认助手不依赖 Bot 管理入口。

## 为什么撤

- 产品方向是**单用户本地工作台**，不再做多用户/多 Bot 平台；
- 多 Bot 辩论链路已删除；
- 页面文案（“站长 Bot 所有人可用”“独立记忆”“最多 3 个”）与 owner 级记忆闭环冲突。

## 以后要恢复

1. 从 git 历史恢复 `frontend/src/BotsView.tsx`；
2. 在 `App.tsx` 加回 `view="bots"`、侧栏按钮与渲染分支；
3. API 和数据库无需迁移。

## 不删数据的边界

`bots.db` 中已有的 Bot 记录仍在；本次只撤 UI，不承诺 API 长期维护。
